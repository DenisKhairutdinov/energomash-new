# energomash

Vite + TypeScript, без фреймворка (vanilla-ts).

## Журнал работ

- В начале сессии прочитай `docs/worklog.md`: там состояние проекта, принятые решения и открытые вопросы.
- После каждого значимого шага (перед коммитом) дополняй журнал: что сделано, что решено, что осталось. Журнал коммитится вместе с изменениями.

## Скиллы

- Скиллы проекта лежат в `.claude/skills/` и подключаются в каждой сессии автоматически.
- Перед каждой задачей сначала определи подходящие скиллы и вызови их через Skill, и только потом приступай к работе. Это относится к дизайну, вёрстке, анимациям, доступности, производительности, SEO, сборке Vite, тестированию в браузере, безопасности и текстам.
- Используй только скиллы из `.claude/skills/` и встроенные скиллы Claude Code (`init`, `simplify`, `code-review`, `security-review`, `run` и т. п.). Личные скиллы из `~/.claude/skills` и плагины, не относящиеся к проекту, не использовать.
- Если для задачи подходящего скилла нет, скажи об этом и работай без него.

## Дизайнерские скиллы вместе

Дизайнерские скиллы дополняют друг друга. Вызывай только те, что нужны на текущем шаге, не все подряд. Подробности и разбор расхождений: `docs/design-skills.md`.

- Приоритет: бриф и проект, затем доступность и производительность, затем рекомендации скиллов.
- Стек vanilla TS + Vite: примеры из React, Tailwind, shadcn переводи в чистый CSS/TS. Цвета и размеры только через CSS-переменные (OKLCH).
- Шрифты только с кириллицей.
- Анимация: один акцентный момент на страницу, остальное по запросу; всегда `prefers-reduced-motion`.
- Правила чужих проектов в скиллах (Switchyard, Arabic/RTL, `~/CLAUDE.md`) игнорируй.
- Если два скилла противоречат друг другу, назови конфликт и реши по приоритету выше.

## Остальные скиллы

Группы, ведущие скиллы и список неприменимых: `docs/other-skills.md`.

- Доступность: планка WCAG 2.2 AA, даже если скилл называет 2.1.
- Анимация: сначала нативный CSS, GSAP для сложных последовательностей, pin и scrub.
- `front-comments`, `front-refactor` запускать только по прямой просьбе.
- Не применять: SaaS-маркетинг (signup, onboarding, paywalls, churn, ASO и т. п.), `raaaf-*`, `gh-cli`, `vite-agents-project-scaffolder`, `gsap-react`, `gsap-frameworks`.
