# Дизайн-бриф (пайплайн awwwards)

Дата: 2026-10-16. Один дизайн: «Кинотеатр цистерны». Первый вариант («Заводской паспорт») удалён по решению владельца.

## Правила владельца (действуют всегда)

- **Палитра** только со старого сайта (`src/styles/base/vars.scss` старого проекта): фон `#f5f5f3`, чернила `#0d0e13`, акцент `#c8603d` (заливки кнопок `#b84f30`), серые `#dededc` и `#7a7a78`, тёмное стекло `#0d0e1399`, размытие 14 px.
- **Никаких скруглений** (радиус 0 у всего, включая переключатели, маркеры, бегунки).
- **Никаких горизонтальных и оранжевых полосок и линий** у блоков: ни разделителей, ни подчёркиваний, ни полос прогресса, ни линий-индикаторов. Разделяем пространством, стеклом и фоном.
- **Никаких контурных букв** (без заливки): только сплошной текст.
- **Никакой бегущей строки.**
- **Курсор системный:** кастомный курсор не используем. Кнопки статичные, за курсором не двигаются.
- **H1 одного тонкого веса (200) везде.**
- **Стекла больше, анимации смелее, композиции уникальные,** сайт максимально современный (не как из 2010).
- **Чертежи** (`ppc.svg`, `shassi.svg` со старого сайта) допустимы в плитках категорий на hero, в лоадере и подвале; в подкатегориях каталога их нет.
- **Название «автоцистерны»** вместо «цистерны на шасси» везде.
- **Типографика:** заголовки (Oswald 200, капсом) нравятся; остальной текст аккуратный и читаемый, без гигантских размеров (карточки: Golos Text 500 с обычным регистром).
- **Правый нижний угол свободен** под виджет чата (на старом сайте там стоял чат).
- **Наличие:** 6 слайдов (5 моделей ППЦТВ-26, ППЦ-28, АЦПТ-10, АТЗ-12, ППЦН-38ТК и финальный «Ещё N моделей»), как на старом сайте.
- **Карта поставок:** отображение и механика как на старом сайте (серые регионы, наливаются акцентом по очереди с запада на восток, стеклянная карточка при наведении, пульсирующая метка завода); композиция блока прежняя (текст слева, карта справа). Регионы без поставок заметно светлее фона.
- **Шапка:** поиск, почта, Max, VK; мега-меню как на старом сайте. Ссылки Max и VK в `src/data/home.json` (`contacts`) пока общие, заменить адресами страниц завода.

## Концепция «Кинотеатр цистерны»

Тёмные полноэкранные главы по одному кадру на экран, крупные фото, стекло поверх фото, пин-скролл (горизонтальная «киноплёнка» отгрузок), фон главы меняется за выбором (каталог по назначению), индикатор глав справа (квадраты). Плавный скролл Lenis, переходы между страницами (View Transitions), прелоадер с чертежом.

## Движение (линза `design-motion-principles`)

Основная Jakub (отполированная сдержанность для B2B), точечно Jhey на hero и входах; Emil для частых действий (меню, фильтры, калькулятор): без анимации на каждое движение. Приёмы: буквы заголовков волной из-под маски, стеклянные карточки въезжают с наклоном и масштабом, рамка фона раскрывается при прокрутке, параллакс и «глубина» карточек, счётчики, шторки на фото. Всё внутри `prefers-reduced-motion: no-preference`.

## Шрифты

Oswald Variable 200–300 (заголовки), Golos Text Variable (текст), JetBrains Mono Variable (технические подписи). Все с кириллицей, самохостинг через fontsource.

## Структура стилей

`src/styles/main.scss` + `src/styles/partials/`: `_layers`, `_tokens`, `_base`, `_mixins` (темы и стекло), `_components`, `_modal`, `_effects` (лоадер, зерно, индикатор глав, чертежи), `_header`, `_hero`, `_stock` (наличие, каталог по назначению), `_story` (цифры, отгрузки, заказ), `_geography`, `_trust` (лизинг, документы, вопросы, блог, заявка), `_footer`. Подпапка обязательна: иначе vituum собирает каждую часть отдельным CSS.

## Референсы

Awwwards через поиск описаний не отдаёт (только названия и оценки). Ориентиры по базе `ui-ux-pro-max`: стиль Brutalism (0px углы, видимая сетка, крупные блоки), паттерн Scroll-Triggered Storytelling (главы, индикатор прогресса).
