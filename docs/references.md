## Выводы для дизайна

1. Шапка: компактная стеклянная таблетка, а не широкая полоса.
2. Один экран = одна мысль, крупное фото техники, короткий текст.
3. Текст читаемым нейтральным гротеском (Onest, Manrope или Geologica), заголовки Oswald 200.
4. Технические данные скобками и моноширинным (характеристики моделей).
5. Гигантская цифра на плоском акцентном блоке (гарантия, число моделей).
6. Проявление текста по словам при прокрутке, фото раскрываются рамкой.
7. Правила владельца из `design-brief.md` сильнее любого референса: без скруглений, без линий-полосок, без контурных букв, системный курсор.

## Просмотр 2026-10-16 (по правилу «каждый элемент сначала смотрим на Awwwards»)

- **Awwwards, категории Industrial и Blog** (галереи): редакционные блоги держатся на крупных снимках и коротком тексте под ними; для нас взято: свежая статья на весь экран, остальные крупными карточками, чёрно-белые фото с цветом по наведению.
- **Cuberto (cuberto.com)**: услуги идут липкой стопкой широких карточек, каждая накрывает предыдущую, номер отнесён вправо. Взято для «Как купить»: стопка карточек на всю ширину с большим номером и стеклянной подписью.
- **Раскрывающиеся панели-полосы** (частый приём победителей для каталогов): наведение раскрывает панель, остальные сжимаются до вертикальной подписи. Взято для «Каталога по назначению».
- **Гигантские цифры на затемнённом фото** с полосой стекла: взято для «Завода в цифрах».
- Недоступны для просмотра в браузере: lusion.co и ряд других доменов (навигация запрещена).
