## Выводы для дизайна

1. Шапка: компактная стеклянная таблетка, а не широкая полоса.
2. Один экран = одна мысль, крупное фото техники, короткий текст.
3. Текст читаемым нейтральным гротеском (Onest, Manrope или Geologica), заголовки Oswald 200.
4. Технические данные скобками и моноширинным (характеристики моделей).
5. Гигантская цифра на плоском акцентном блоке (гарантия, число моделей).
6. Проявление текста по словам при прокрутке, фото раскрываются рамкой.
7. Правила владельца из `design-brief.md` сильнее любого референса: без скруглений, без линий-полосок, без контурных букв, системный курсор.

## Просмотр 2026-10-16 (по правилу «каждый элемент сначала смотрим на Awwwards»)

- **Awwwards, категории Industrial и Blog** (галереи): редакционные блоги держатся на крупных снимках и коротком тексте под ними; для нас взято: свежая статья на весь экран, остальные крупными карточками, чёрно-белые фото с цветом по наведению.
- **Cuberto (cuberto.com)**: услуги идут липкой стопкой широких карточек, каждая накрывает предыдущую, номер отнесён вправо. Взято для «Как купить»: стопка карточек на всю ширину с большим номером и стеклянной подписью.
- **Раскрывающиеся панели-полосы** (частый приём победителей для каталогов): наведение раскрывает панель, остальные сжимаются до вертикальной подписи. Взято для «Каталога по назначению».
- **Гигантские цифры на затемнённом фото** с полосой стекла: взято для «Завода в цифрах».
- Недоступны для просмотра в браузере: lusion.co и ряд других доменов (навигация запрещена).

## Просмотр источников (2026-10-17, в браузере)

Подробный разбор по источникам: `docs/reference-sources.md`, раздел «Итоги просмотра в браузере».

- **T3.tech (через Lapa Ninja, категория Automotive):** мелкая моноширинная подпись слева и крупный текст справа; изометрические чертежи машин, соединённые линиями с узлами; смена тёмного блока на кремовый вместе с цветом шапки. Берём для: ряда моделей на главной и блока «Завод в цифрах».
- **Component Gallery, Accordion:** `details/summary` или кнопка с `aria-expanded`; поворот стрелки по атрибуту; не прятать важное; осторожно с режимом «открыт один». Берём для: FAQ.
- **ReUI Filter Sidebar:** счётчики у вариантов, применённые чипы с «Clear all», ползунок диапазона, «Apply» и «Reset». Берём для: проверки фильтров каталога (чипы применённых условий, сброс одним действием).
- **Minimal Gallery (JARCOS, GRNDWRK, DRAȘA):** огромный дисплейный шрифт, строгая сетка, много воздуха. Берём для: заголовков разделов.
- **Недоступно или ограничено:** Godly (редирект на recent.design, прямой доступ запрещён), Hover States (заглушка), Nicelydone (после регистрации), SaaSFrame (3 примера бесплатно).

## Awwwards, победители (2026-10-17, живые сайты со скроллом)

Приоритетный источник. Адреса берутся со страницы `awwwards.com/sites/<slug>` (ссылка «Visit Site»).

- **Terminal Industries** (`terminal-industries.com`): светлая серая основа, стеклянная панель-навигация, сетка логотипов на линиях, три карточки со сдвигом вниз у средней. Взято для системы C (карточки отгрузок со сдвигом, светлая основа).
- **Q Industrial** (`q-industrial.com`): чёрный фон, тонкая светлая гротеска, списки-строки «метка и название» на волосяных линиях, полноэкранные тёплые фото. Взято для системы B (строки-реестры наличия и назначения).
- **Kraken Industries** (`krakenindustries.co`): три колонки «01, 02, 03» на линиях, плоская акцентная полоса с огромным «10 YR», моноширинные подписи. Взято для B (акцентные полосы сервиса, субсидии и подвала, ячейки на линиях).
- **Turion Space** (`turionspace.com`): крупные заявления справа на тёмном, мелкие метки по краям. Взято для крупных заявлений в C.
- Вне ниши и не подошли: Scheme Engine (киностудия, зашёл по слову «engine»).
- Не открылись браузером: Volvo Trucks, Divergent (скриншоты запрещены), Linear changelog и Vercel blog (домен запрещён).
